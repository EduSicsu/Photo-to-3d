# Cosmos garden

A static Three.js garden. No package installation or build step is needed.

To preview on a computer with Python 3, open a terminal in this folder and run:

```sh
python3 -m http.server 8077
```

Then open http://localhost:8077/. Use a local web server rather than opening index.html directly, because the scene loads JavaScript modules and assets.

The plant assets' credits are in assets/planting/CREDITS.txt; font and Three.js licenses are included alongside those assets.
